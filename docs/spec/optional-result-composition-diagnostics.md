# 任意・結果の合成

## 局所伝播

`任意から値を取り出すか戻る`と`結果から成功値を取り出すか戻る`は、利用者定義単語の
現在のフレームだけを対象にする制御構文です。組み込み語ではなく、`メイン`、初期値、配列要素式では
使用できません。両方の正規表記は予約され、`format`でも同じ綴りを出力します。

入口を `S 任意<T>` とした場合、通常経路は `S T` です。値なし経路では、単語の宣言出力が
`S 任意<U>` と完全一致するときだけ `S ない<U>` を返します。入口を `S 結果<T,E>` とした場合、
通常経路は `S T`、失敗経路は宣言出力 `S 結果<U,E>` です。失敗ペイロードは変更しません。

`S`の個数・順序・型、および結果の失敗型`E`は完全一致が必要です。入力不足には
`E_STACK_UNDERFLOW`、入力ラッパー型の不一致には`E_TYPE_MISMATCH`を使います。

| 診断 | 条件 |
|---|---|
| `E_OPTIONAL_PROPAGATION_CONTEXT` | 利用者単語外、または出力末尾が`任意<U>`でない |
| `E_OPTIONAL_PROPAGATION_EFFECT_MISMATCH` | 保持するprefixが宣言出力と一致しない |
| `E_RESULT_PROPAGATION_CONTEXT` | 利用者単語外、または出力末尾が`結果<U,E>`でない |
| `E_RESULT_PROPAGATION_EFFECT_MISMATCH` | prefixまたは失敗型が宣言出力と一致しない |

## 配列要素

`任意<T>`と`結果<T,E>`は配列要素型にできます。表示可能性、等値比較可能性、trace非開示は型引数から
推移的に決まります。配列構築子はラッパーの内側も含めて数え、値全体で最大2個です。このため
`配列<任意<配列<整数>>>`は有効ですが、`配列<任意<配列<配列<整数>>>>`は
`E_NESTED_ARRAY_NOT_AVAILABLE`です。

2次元配列の論理葉数は、選択中のラッパーペイロードをたどって数えます。値なしと非選択側は0、
選択されたスカラーは1、選択された配列はその論理葉数を加算します。これによりラッパーを使った
配列資源上限の迂回を認めません。
