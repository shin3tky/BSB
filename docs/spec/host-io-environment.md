# IO-ENV機能グループ: 実行環境情報、待機、時計、日時

> 本文は現行実装の規範契約です。

8BはOSや埋込みホストに依存する値を、差し替え可能な実行環境能力から取得します。Javaの`System`、既定ロケール、既定タイムゾーンを組み込み語から直接参照しません。

## 1. 能力と単語

| 能力名 | 正規語 | スタック効果 |
|---|---|---|
| `process.arguments` | `起動引数を得る` | `（-- 配列<文字列>）` |
| `program.identity` | `プログラム名を得る` | `（-- 文字列）` |
| `program.identity` | `プログラムの場所を得る` | `（-- 文字列）` |
| `time.sleep` | `待つ` | `（整数 --）` |
| `time.monotonic` | `単調ミリ秒を得る` | `（-- 整数）` |
| `time.wall` | `現在日時を得る` | `（-- 日時）` |
| なし | `日時を文字列に変換する` | `（日時 -- 文字列）` |

不足能力は、到達した呼出しで`E_CAPABILITY_UNAVAILABLE`です。`check`は能力を呼びません。

## 2. 起動引数とプログラム識別

公開CLIは次の形で`run`だけに引数を渡します。

```text
bsb run program.bsb -- arg1 arg2
```

区切り`--`自体、サブコマンド、ソースパスは`起動引数を得る`へ含めません。`--`がなければ空配列です。`check`と`format`へ`--`以降を指定した場合はCLI使用法エラー2です。

引数はUnicodeスカラー値列として渡します。各文字列は16 MiB以下、配列は65,536要素以下、全引数のUTF-8長合計は64 MiB以下です。呼出しごとに同じ不変配列値を返し、配列構築予算を要素数だけ消費します。

`プログラム名を得る`は論理名を返します。CLIではソースの最終パス要素をそのまま使い、`.bsb`を除きません。埋込みホストは非空の論理名を明示します。

`プログラムの場所を得る`は絶対URI文字列を返します。CLIのローカルソースは正規化した`file:` URIです。区切り文字やドライブ文字を持つOS固有パスを言語値へ直接公開しません。場所を持たない埋込みプログラムでは能力不足です。IO機能グループではURIを使ったファイル操作を提供しません。

## 3. 待機と単調時計

`待つ`の入力はミリ秒です。0から86,400,000までを1呼出しで受理し、負数または超過は`E_WAIT_DURATION_RANGE`です。1実行の要求合計は604,800,000ミリ秒で、超過は`E_WAIT_TOTAL_LIMIT`です。

待機能力は、完了または取消を返します。取消は`E_WAIT_CANCELLED`です。成功時だけ累積待機量を増やします。待機中の実時間は30秒の能動実行時間へ数えません。テストでは実時間を経過させない偽の待機能力を使います。

`単調ミリ秒を得る`は実行開始を0とする非減少の経過ミリ秒を返します。入力待ちと`待つ`の時間も経過値には含みますが、能動実行時間予算からは除外します。分解能未満は切り捨てます。能力が前回値より小さい値を返す場合は利用者診断ではなく実行環境契約違反の内部エラー70です。

## 4. 日時

`日時`を新しい具体型にします。値はエポックミリ秒と、その取得時に実行環境が選んだUTCオフセットを保持する不変値です。オフセットは分単位、範囲は-18:00から+18:00です。`日時`は利用者定義効果に使えますが、`表示可能`、`等しい`、配列要素型には含めません。現在日時は副作用なしの初期値ではないため、ソース上の定数・変数を`現在日時を得る`で初期化できません。

`現在日時を得る`は呼出しごとに能力から1値を取得します。既定ロケール・既定タイムゾーンを暗黙参照しません。年は0000から9999までとし、表現不能値は`E_DATETIME_RANGE`です。

`日時を文字列に変換する`は次のASCII固定形式を返します。

```text
uuuu-MM-dd'T'HH:mm:ss.SSSXXX
2026-08-29T14:05:06.123+09:00
2026-08-29T05:05:06.123Z
```

数字はASCII、月日と時分秒は2桁、ミリ秒は常に3桁、UTCは`Z`、その他は`+HH:MM`または`-HH:MM`です。ロケール名、曜日、夏時間略称、うるう秒を出しません。

## 5. 8Aとの時間境界

実行器は、資源制限用の能動時間、利用者へ公開する単調時間、現在日時を別の役割として保持します。同じテスト時計から構成しても、組み込み語の呼出しが資源計測値を進めたり巻き戻したりしてはなりません。トレース整形中に時計を追加で読みません。

## 6. 対象外

環境変数、作業ディレクトリ、ユーザー名、ホスト名、乱数、タイムゾーン変換、日時解析・加減算、カレンダー、音・通知・音声再生はIO機能グループに含めません。音声は独立した拡張能力として後で決めます。
