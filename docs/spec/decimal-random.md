# RNG機能グループ: 一様小数乱数

> 本文は現行実装の規範契約です。

[一様整数乱数](integer-random.md)を拡張し、下限・上限・小数桁数を指定した
正確な10進小数の一様乱数を提供します。通常の疑似乱数として扱い、連続する実数全体の一様分布、
正規分布、暗号用乱数、BSBソースからのシード操作は機能範囲に含めません。

## 1. 単語と入力

```text
小数乱数を得る    （小数 小数 整数 -- 小数）
```

入力順は下限 `a`、上限 `b`、小数点以下の桁数 `p` です。下限・上限の両方を含みます。
整数と小数の暗黙変換はありません。桁数は省略できません。

```text
メインとは （--）
    -1.0 と 1.0 と 2 で 小数乱数を得る 一行表示する
こと。
```

この例は `-1.00、-0.99、…、0.00、…、0.99、1.00` の201個から等確率で選びます。
表示は既存の小数正規形に従うので、例えば `-1.0`、`0.0`、`0.5` と表示します。

## 2. 桁数・境界・候補集合

`p` の許容範囲は **0〜65,536** とします。指定するのは格子の間隔 `10^(-p)` であり、
有効桁数、出力の文字数、表示上の末尾0の個数ではありません。
`p = 0` も小数型を返し、整数値に相当する候補は `1.0` などと表示します。

両端が指定した格子上にあることを要求します。すなわち、次の両方が整数でなければエラーです。

```text
A = a × 10^p
B = b × 10^p
```

正規小数の係数を `c`、スケールを `s` とすると、これは `s <= p` と同値です。
0の正規スケールは0です。境界を切上げ・切捨て・最近接丸めで格子へ移しません。
例えば `0.005〜0.015` を小数2桁では指定できません。小数3桁なら両端を含めて指定できます。
この検査は両端が同じ場合にも行います。

`a <= b` のとき、候補集合と個数は次です。

```text
G = { J × 10^(-p) | Jは整数、A <= J <= B }
N = B - A + 1
```

成功した取得では、各候補を同じ確率 `1 / N` で返します。ただし第5節の数値上限を満たす範囲に限ります。

| 下限 | 上限 | p | 候補 | 個数 |
|---|---|---:|---|---:|
| `0.0` | `1.0` | 1 | `0.0、0.1、…、1.0` | 11 |
| `0.0` | `1.0` | 2 | `0.00、0.01、…、1.00` | 101 |
| `0.0` | `0.99` | 2 | `0.00、0.01、…、0.99` | 100 |
| `-1.0` | `1.0` | 2 | `-1.00、-0.99、…、1.00` | 201 |
| `-2.0` | `2.0` | 0 | `-2.0、-1.0、0.0、1.0、2.0` | 5 |
| `0.25` | `0.25` | 2 | `0.25` | 1 |

上限1を含めたくない場合は、指定格子の最後の値を上限にします。半開区間を切り替える追加引数は導入しません。

## 3. 生成と一様性

1. 入力値域・数値上限と必要能力を第6節の順で検査します。
2. `a = b` なら下限と同じ小数値を返します。乱数源を呼びません。
3. `A`、`B`、`N` を任意精度整数で正確に作ります。
4. 整数乱数と共通の棄却法で `0 <= X < N` を一様に選びます。
5. `J = A + X` から、係数 `J`、スケール `p` の正確な小数を作り、既存の小数正規形へ戻します。

二進浮動小数、丸め付き小数除算、生成後の丸め、剰余による範囲変換は使いません。
Java実装では既存の `DecimalValue(BigInteger coefficient, int scale)` で第5項を表現できます。
`MathContext` による精度丸めを加えません。

整数 `J` と候補値 `J × 10^(-p)` は一対一です。末尾0の正規化は数値を変えないため、候補を合流させません。
例えば格子の `0.50` は `0.5` と表示されても、他の格子点と同じ確率で選ばれます。

公平で独立なビットを仮定し、`k = bitLength(N - 1)`、`r = 1 - N / 2^k`、
候補生成上限を `M` とします。`N > 1` で特定の値を返す確率は `(1 - r^M) / N`、
全試行が棄却される確率は `r^M` です。成功を条件にした各候補の確率は正確に `1 / N` です。
有限状態の疑似乱数源の完全な独立性を保証するものではありません。

## 4. 型と表示

返す型は常に既存の `小数` です。`p = 0`、両端一致、結果0でも整数型へ変更しません。
正規化・等価性・ハッシュ・表示・配列要素としての利用は既存の小数契約をそのまま適用します。

- 0は `0.0` と表示し、負の0を作りません。
- 不要な末尾0を保持しません。指定桁数を結果値の表示情報として保存しません。
- 候補格子の識別は数値で行います。書式やリテラルの元のスケールに依存しません。
- 固定桁表示が必要な場合の書式機能は、本機能と別に扱います。

## 5. 数値上限と許容範囲

既存の小数値は有効桁数 `D = 65,536`、スケール絶対値 `S = 65,536` 以下です。
本機能では `0 <= p <= min(D, S)` とします。巨大な結果を再抽選で除外すると宣言した分布が変わるため、
**範囲内のすべての格子点を表現できることを、乱数源の呼出し前に検査**します。

`a < b` の場合、次を追加の許容条件とします。

```text
|a| <= 10^(D - p)
|b| <= 10^(D - p)
```

格子上の両端について、これは `-10^D <= A <= B <= 10^D` と同値です。
すべての係数 `|J| < 10^D` はD桁以下です。端の `J = ±10^D` だけはD+1桁ですが、
正規化すると係数 `±1`、スケール `p - D` となり、既存の小数値上限内です。
したがって、小数65,536桁で `-1.0〜1.0` を指定する最大精度の範囲も受理できます。

この条件は、両端が異なる区間に対して必要でもあります。許容係数範囲を越えて2個以上の連続整数を
候補に含めると、D桁を超え、かつ10で割り切れない係数が少なくとも1個あります。
その値は正規化してもD桁を超えるため、すべての候補を表現する契約に適合しません。

`a = b` の場合は、この範囲幅に由来する追加条件を課しません。既存の合法な小数値であり、
指定格子上にあればその値だけを返せます。巨大な `a × 10^p` の内部整数を構築する必要もありません。
両端一致でも、第2節の格子検査と必要能力の検査は行います。

上記の非退化な範囲では、内部係数の絶対値は `10^D` 以下、候補数は `2 × 10^D + 1` 以下です。
内部整数には最大65,537桁を許します。これらを利用者向けの整数値としてスタックへ積みません。
採用後の小数は必ず既存の値上限を満たします。

## 6. 診断と判定順

静的検査では既存の `E_TYPE_MISMATCH` と `E_STACK_UNDERFLOW` を使います。
3入力の具体型を固定し、整数の境界値を暗黙に小数へ変換しません。

実行時は次の順で、最初の診断1件を返します。

1. `p` が0〜65,536外: `E_RANDOM_DIGITS_OUT_OF_RANGE`。
2. `a > b`: 既存の `E_NUMERIC_RANGE_INVALID`。
3. 下限が指定格子上にない: `E_RANDOM_BOUND_NOT_ALIGNED`。
4. 上限が指定格子上にない: 同じ `E_RANDOM_BOUND_NOT_ALIGNED`。
5. `a < b` で第5節の条件を満たさない: `E_RANDOM_RANGE_PRECISION_LIMIT`。
6. `random.bytes` 能力がない: 既存の `E_CAPABILITY_UNAVAILABLE`。
7. `a = b` ならその値を返し、それ以外なら候補生成を開始します。

桁数の検査は、ホストの `int` への変換や10の累乗の構築より前に、任意精度整数で行います。
格子検査は正規スケールで行い、数値上限の検査は境界の絶対値と `10^(D - p)` の正確な比較で行えます。
不正な大きさの内部係数を先に構築してから判定する必要はありません。

| 診断コード | 主な構造化フィールド |
|---|---|
| `E_RANDOM_DIGITS_OUT_OF_RANGE` | `word`、`digitsPreview`、必要時の `digitsCodePoints`、`minimum=0`、`maximum=65536` |
| `E_RANDOM_BOUND_NOT_ALIGNED` | `word`、`bound=lower/upper`、`digits`、`scale`、`valuePreview`、必要時の `valueCodePoints` |
| `E_RANDOM_RANGE_PRECISION_LIMIT` | `word`、`digits`、`precisionLimit=65536`、`maximumAbsoluteBoundExponent`、`lowerPreview`、`upperPreview`、必要時の両端の長さ |

`maximumAbsoluteBoundExponent` は `D - p` です。入力のプレビューと省略前の長さは既存の数値診断規則に従います。
新規診断の位置は `小数乱数を得る` の呼出しspan、段階はruntime、通常の実行時エラー終了コードは10です。
修正案はそれぞれ「桁数を許容範囲内にする」「境界を指定格子に揃えるか桁数を増やす」
「境界の絶対値を小さくするか桁数を減らす」とします。

## 7. 能力・資源・原子性

必要能力と副作用は整数乱数と共通の `random.bytes` とします。
CLI、`ExecutionContext.standard`、注入源、シード再現性の範囲は既存の整数乱数契約を引き継ぎます。
整数乱数と小数乱数で別の源を作らず、同じ実行環境の状態を呼出し順に消費します。

候補生成上限は共通の `RuntimeLimits.RANDOM_ATTEMPTS = 1,024`、採用は最後の候補も含めて許します。
すべて棄却された場合は `E_CAPABILITY_FAILURE`、`capability=random.bytes`、`operation=sample` とし、
代替値を返しません。バイト取得失敗は整数乱数と同じ能力失敗処理を使います。

候補生成の前後で既存の能動実行時間を検査します。加えて、内部係数・候補数の構築後と
小数の正規化後、スタックへの確定前にも時間上限を検査します。
超過は既存の `E_EXECUTION_TIMEOUT` とし、候補生成や棄却をIR命令数へ加算しません。

失敗時は3入力とその下のスタック、大域・局所値、標準出力を変更しません。
先に消費した乱数源の状態や実行時間は巻き戻しません。
乱数源からの候補が数値上限を超えたことを理由に再抽選する処理は導入しません。

## 8. 説明・IR・整形・トレース

辞書の機能グループは既存の `RNG`、型規則は `fixed`、能力・副作用は `random.bytes` とします。
整数乱数語の名前・スタック効果・生成列・候補予算は変更しません。

`check`、`format`、`explain` は乱数源を呼びません。静的検査だけで値域エラーを先取りせず、
整数乱数と同じく到達した実行時呼出しで判定します。
既存の小数型と通常の組み込み呼出しIRを使い、新しい値型や構文は追加しません。
辞書の末尾へ追加し、既存語の公開順を維持します。

成功した呼出しのトレース効果は `random.bytes`、結果値は既存の小数表示と省略規則に従います。
候補・シード・棄却回数は記録しません。トレースの有無で生成列や源の呼出し回数を変えません。

## 9. 実装と適合性

整数乱数と小数乱数は、内部の任意精度整数サンプラーを共有します。
小数乱数のために、利用者向けの `整数乱数を得る` を合成IRで呼び出したり、中間整数を
データスタックへ積んだりしません。既存の整数乱数テストをそのまま通すことを条件とします。

検証は次を含めます。

- 小さい候補集合を列挙し、各格子点の採用回数が揃うこと。0、負数、両端、棄却候補を含める。
- 候補数11・101・100・201の例と、生成後に丸めないこと。
- `p = 0`、`p = 65,536`、桁数範囲外、型違い、入力不足、逆順の両端。
- 両端の格子不一致、末尾0正規化後の格子一致、両端一致時の格子検査と源の非呼出し。
- 係数 `±10^D` の正規化、第5節の境界ちょうどと超過、追加条件を適用しない合法な両端一致。
- 失敗時の入力保持、能力不足・能力失敗、候補上限、確定前の時間超過。
- 固定シードで整数乱数と小数乱数を混在させた呼出し順の再現、トレース不変性。
- CLIの `check`、`run`、`format`、`explain` と、生成結果を小数配列へ格納する例。

`tests/conformance/decimal-random` の `normal.tsv` と `diagnostics.tsv` を
`DecimalRandomConformanceTest` が実行し、候補・出力・源の呼出し回数・診断フィールド・日本語メッセージを検証します。
候補列挙・数値上限・失敗原子性・混在する生成列とトレースは `DecimalRandomRuntimeTest`、
公開コマンドは `DecimalRandomCliTest` が検証します。
統計的な頻度の閾値による合否判定は使いません。
