# IO機能グループ: 正規整形

> 本文は現行実装の規範契約です。

IO機能グループは新しいソース構文、リテラル、制御中間語を追加しません。新しい型名と組み込み語は既存の識別子規則で字句化し、[language-core-format.md](language-core-format.md)から[text-regex-format.md](text-regex-format.md)までの行分け、助詞、字下げ、コメント、BOM、LF、末尾LFをそのまま使います。

## 1. 正規名

入力語、状態判定語、標準エラー語、終了語、実行環境語、型名に別名はありません。フォーマッタは識別子の限定変換とNFC正規化だけを行い、意味解析や能力検査は行いません。

## 2. CLIの`--`

`bsb run source.bsb -- args...`の`--`はCLI引数であり、BSBソースのトークンではありません。`format`の出力へ現れず、プログラム引数も整形結果へ影響しません。

## 3. 失敗ソース

型不一致、能力不足、入力結果の状態違い、終了コード範囲、待機・日時・資源エラーは構文エラーではありません。構文として有効なソースは`format`に成功し、入力非変更または既存規則による正規化を行います。成功出力は2回目も同じバイト列でなければなりません。
