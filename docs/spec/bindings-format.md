# BIND機能グループ: 宣言と代入のフォーマッタ仕様

> 本文は現行実装の規範契約です。
>
> [language-core-format.md](language-core-format.md)と[control-flow-format.md](control-flow-format.md)へ追加する規則を定めます。

## 1. 基本原則

`format`はFLOW機能グループまでと同じくUTF-8、字句、構文だけを検査します。名前、スコープ、初期化、型、スタック効果、到達可能性は検査しません。

出力はBOMなしUTF-8、LF改行、末尾LFちょうど1個です。FLOW機能グループまでの構文だけからなる入力の標準形は変更しません。

## 2. コメントを含まない宣言

初期値内にコメントがない宣言は1行へまとめます。

```text
単価は 定数 120。
累計は 変数 0。
小計は 定数 単価 と 個数 を 掛ける。
```

- 宣言名と`は`の間に空白を入れない
- `は`と`定数`または`変数`の間にASCII空白1個を置く
- 宣言種別と空でない初期値の間にASCII空白1個を置く
- 初期値の通常要素はCORE機能グループの本体行と同じ空白で区切る
- 最後の初期値要素と`。`の間に空白を入れない
- 空の初期値は`名前は 定数。`または`名前は 変数。`とする

空の初期値は静的エラーですが構文上有効であるため、`format`は成功します。

大域宣言は字下げせず、単語本体直下の局所宣言はASCII空白4個、制御ブロック内は既存の深さに従います。

## 3. コメントを含む宣言

初期値内にコメントが1個でもある場合は、宣言ヘッダー、初期値、終端を複数行に分けます。

```text
小計は 定数
    単価 と 個数 を 掛ける # 税抜き小計
。
```

宣言ヘッダーは`名前は 定数`または`名前は 変数`で終えます。初期値の実行要素とコメントは宣言より1段深くし、終端`。`は宣言と同じ字下げの独立行にします。

行末コメントは直前の初期値行へASCII空白1個で付け、コメントだけの行は初期値の字下げへ置きます。コメントを越えて実行要素を移動しません。コメント本文と本文内の空白は変更しません。

## 4. 代入

代入の4要素は同じ行へ置き、ASCII空白1個で区切ります。

```text
100 を 累計 に 入れる
累計 と 小計 を 足す を 累計 に 入れる
```

代入より前の未確定行に値を作る要素があれば同じ行へ結合します。代入の`を`、対象名、`に`、`入れる`の間にはコメントを置けないため、コメントを越えた結合はありません。

`入れる`で本体の1実行行を確定します。後続の実行要素は次の行へ出力します。同じ物理行の`入れる`より後ろにコメントがある場合は、その代入行へASCII空白1個で付けます。

## 5. トップレベルの配置

大域宣言と単語定義は元ソースの順序を維持します。異なるトップレベル要素の間には空行1行を置きます。連続する大域宣言どうしの間には空行を置きません。

```text
単価は 定数 120。
個数は 定数 3。

メインとは （--）
    単価 を 一行表示する
こと。
```

トップレベルコメントの前後関係はCORE機能グループどおり保持します。コメントを宣言や単語定義の反対側へ移動しません。

## 6. 制御ブロック内の宣言

条件分岐の各側、回数ループ本体、条件ループの条件計算部と本体では、現在の制御構文深さを宣言の基礎字下げにします。宣言は制御開始語・中間語・終了語と結合しません。

```text
はい ならば
    表示文は 定数 「真です」。
    表示文 を 一行表示する
つぎに
```

空の制御本体、到達不能な宣言、スコープ外参照、型不一致を構文どおり保持します。

## 7. 代替区切り

入力でタブ、全角空白、`、`、`，`を使用しても、宣言と代入のトークン間はASCII空白1個へ統一します。識別子と`は`の隣接違反は構文エラーであり、フォーマッタが修復して成功させることはありません。

## 8. 冪等性

任意のBIND機能グループまでの構文として有効なソース`S`について、バイト列として次を満たします。

```text
format(format(S)) = format(S)
```

適合試験では、大域・局所・ブロック宣言、コメントを含む複数行初期値、代入、静的失敗を含むすべてのformat成功ケースへ2回目の適用を行います。
