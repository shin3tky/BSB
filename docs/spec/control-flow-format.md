# FLOW機能グループ: 制御構文のフォーマッタ仕様

> 本文は現行実装の規範契約です。
>
> [language-core-format.md](language-core-format.md)へ追加する規則を定めます。

## 1. 基本原則

`format`はCORE機能グループと同じくUTF-8、字句、構文だけを検査します。名前、型、スタック効果、制御フロー、到達可能性は検査しません。

出力はBOMなしUTF-8、LF改行、末尾LFちょうど1個です。空入力だけは0バイトです。CORE機能グループの構文だけからなる入力の標準形は変更しません。

制御構文の字下げ単位はASCII空白4個です。単語本体の基礎字下げを1段とし、条件分岐またはループの本体へ入るたびに1段増やします。

## 2. 条件分岐

条件を作る未確定行がある場合、`ならば`をASCII空白1個でその行の末尾へ付け、行を確定します。未確定行がない場合は、`ならば`だけを現在の字下げで出力します。

`さもなければ`と`つぎに`は、対応する`ならば`と同じ字下げの独立行です。真側と偽側は1段深く字下げします。

```text
1 と 2 を 比べて小さい ならば
    「小さい」を 一行表示する
さもなければ
    「小さくない」を 一行表示する
つぎに
```

入力で改行されていても、条件を作る行と`ならば`の間にコメントがなければ上の標準形へ統合します。

コメントが間にある場合はコメントを越えて移動せず、`ならば`を独立行にします。

```text
はい
# 条件についての説明
ならば
つぎに
```

空の真側、空の偽側を許し、中身を補いません。

## 3. 回数ループ

回数を作る未確定行がある場合、`回だけ`をASCII空白1個で末尾へ付けます。未確定行がない場合は`回だけ`を独立行にします。ループ本体は1段深くし、`繰り返す`は`回だけ`の行と同じ字下げに戻します。

```text
3 回だけ
    「反復」を 一行表示する
繰り返す
```

回数を作る最後の要素が単語呼出しであっても、その呼出し行へ`回だけ`を付けます。

```text
1 と 2 を 足す 回だけ
    改行する
繰り返す
```

コメントを越えて`回だけ`を前の行へ移しません。

## 4. 条件ループ

`ここから`、`続く間`、`繰り返す`は、すべてループの基礎字下げに置く独立行です。条件計算部と本体は、どちらも1段深くします。

```text
ここから
    1 と 2 を 比べて小さい
続く間
    「本体」を 一行表示する
    打ち切る
繰り返す
```

条件計算部または本体が空でも、開始・中間・終了の3行を省略しません。

## 5. 制御移行

`打ち切る`、`続ける`、`戻る`は、それぞれ現在の字下げに置く独立行です。前後のリテラル、助詞、呼出しと同じ行へ結合しません。

```text
2 回だけ
    続ける
繰り返す

戻る
```

同じ物理行にコメントがある場合は、CORE機能グループの規則どおりASCII空白1個を置いて制御移行行へ付けます。

## 6. コメント

コメントは字句上の前後関係を越えて移動しません。

- 制御開始語の直後にある行末コメントは開始語の行へ付ける
- `さもなければ`、`つぎに`、`続く間`、`繰り返す`の行末コメントもその行へ付ける
- 制御本体内のコメントだけの行は、その本体と同じ深さへ字下げする
- コメント本文と本文中の空白は変更しない
- 空の制御本体にあるコメントだけの行も削除しない

## 7. 入れ子

開始語を出力した後に深さを1増やし、中間語または終了語を出力する前に対応する深さまで戻します。異なる構文を入れ子にしても、字下げは字句上の入れ子だけで決まります。

```text
2 回だけ
    はい ならば
        ここから
            いいえ
        続く間
        繰り返す
    つぎに
繰り返す
```

深さ256の有効な入力を整形できます。257段目は構文エラーであるため、標準出力を生成しません。

## 8. 到達不能コードと静的失敗

`format`は到達可能性を検査しないため、`戻る`の後ろにある要素も削除しません。また、分岐やループのスタックが一致しない入力、負の回数、制御移行時の効果不一致も、構文として有効なら整形します。

## 9. 冪等性

任意のFLOW機能グループまでの構文として有効なソース`S`について、バイト列として次を満たします。

```text
format(format(S)) = format(S)
```

適合試験では、elseあり・なし、空本体、コメント、異種入れ子、制御移行、静的失敗を含むすべてのformat成功ケースへ2回目の適用を行います。
