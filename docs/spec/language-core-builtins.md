# CORE機能グループ: 組み込み単語辞書

> 本文は現行実装の規範契約です。

## 1. 共通事項

CORE機能グループの組み込み単語は7個です。別名集合はすべて空です。機能グループはすべて `2` です。

整数演算は符号付き任意精度整数で正確に行います。結果の有効桁が65,536桁を超える場合は、結果値を確定する前に `E_INTEGER_RESULT_LIMIT` とします。

2入力の単語は、スタック上で下にある値を第1入力、上にある値を第2入力として消費します。関係のない、さらに下の値は保持します。

## 2. 数値演算

### 足す

```text
足す （整数 整数 -- 整数）
```

- 説明: 第1入力と第2入力の整数を加えます。
- 計算: `結果 = 第1入力 + 第2入力`
- 副作用: なし
- 例: `20 と 22 を 足す` → `42`

### 引く

```text
引く （整数 整数 -- 整数）
```

- 説明: 第1入力から第2入力を引きます。
- 計算: `結果 = 第1入力 - 第2入力`
- 副作用: なし
- 例: `50 と 8 を 引く` → `42`
- 反例: `8 と 50 を 引く` → `-42`

### 掛ける

```text
掛ける （整数 整数 -- 整数）
```

- 説明: 第1入力と第2入力の整数を掛けます。
- 計算: `結果 = 第1入力 × 第2入力`
- 副作用: なし
- 例: `21 と 2 を 掛ける` → `42`

## 3. 等価性

### 等しい

```text
等しい （T T -- 真偽）
```

- 説明: 同じ型の2つの値が等しいかを調べます。
- 型制約: `T` は `整数`、`真偽`、`文字`、`文字列` のいずれか1つで、両入力は同じ型です。
- 副作用: なし

型ごとの等価性は次のとおりです。

| 型 | 等しい条件 |
|---|---|
| `整数` | 数学的な整数値が同じ |
| `真偽` | どちらも `はい`、またはどちらも `いいえ` |
| `文字` | 保持するUnicodeスカラー値列が完全に同じ |
| `文字列` | 保持するUnicodeスカラー値列が完全に同じ |

文字と文字列をNFC、大小文字、ロケール、見た目で暗黙に正規化しません。したがって、合成済みの `が` と `か` + 結合濁点は、見た目と書記素クラスタ数が同じでも、保持するスカラー値列が違えば `いいえ` です。

異なる型の入力は `いいえ` ではなく、実行前の `E_TYPE_MISMATCH` です。

## 4. コンソール出力

出力能力の正規名は `console.output` とします。`表示する`、`一行表示する`、`改行する` はこの能力を要求します。テストではUTF-8バイト列を受け取る出力先へ差し替えます。

表示表現は次のとおりです。

| 型 | UTF-8へ符号化する内容 |
|---|---|
| `整数` | 符号付き10進表記。正数に `+` を付けず、不要な先頭の0を付けない。0は `0` |
| `真偽` | `はい` または `いいえ` |
| `文字` | 保持するUnicodeスカラー値列 |
| `文字列` | 保持するUnicodeスカラー値列。引用符を付けない |

OS固有の行区切りは使用せず、改行は常にLF 1バイトです。

1回の呼び出しが標準出力64 MiB上限を超える場合、その呼び出しの出力を一部も書かず `E_OUTPUT_LIMIT` にします。過去に正常に書かれた出力は取り消しません。

### 表示する

```text
表示する （表示可能 --）
```

- 説明: 値を改行せず表示します。
- 入力: `整数`、`真偽`、`文字`、`文字列` のいずれか
- 出力: なし
- 副作用: `console.output`
- 例: `42 を 表示する` → UTF-8 `42`

### 一行表示する

```text
一行表示する （表示可能 --）
```

- 説明: 値を表示し、その直後にLFを1つ出力します。
- 入力: `整数`、`真偽`、`文字`、`文字列` のいずれか
- 出力: なし
- 副作用: `console.output`
- 例: `「完了」を 一行表示する` → UTF-8 `完了\n`

値の表示とLFを合わせた全体を、出力上限に対する1回の原子的な書き込みとして検査します。

### 改行する

```text
改行する （--）
```

- 説明: 値を表示せずLFを1つ出力します。
- 副作用: `console.output`
- 例: `改行する` → LF 1バイト

## 5. 型制約名

`T` はこの辞書内の `等しい` の対応する型変数、`表示可能` は出力3単語の入力型集合を説明するための辞書専用名です。利用者定義単語のスタック効果には書けません。使用した場合は `E_TYPE_CONSTRAINT_NOT_ALLOWED` です。

## 6. 辞書が公開する項目

各組み込み単語の辞書項目は次を返せなければなりません。

```text
正規名
別名集合
一文説明
入力型列
出力型列
型制約
副作用集合
機能グループ
使用例
```

CORE機能グループではこの情報をJava内部APIとテストから取得できればよく、公開CLIは後続機能グループで追加します。
