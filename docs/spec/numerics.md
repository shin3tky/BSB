# NUM機能グループ: 数値演算

> 本文は現行実装の規範契約です。
>
> CORE〜ARRAY機能グループの規則は、ここで明示的に変更する箇所以外、引き続き有効です。
>
> EXP機能グループでは[指数表記仕様](exponent-literals.md)が、指数表記を追加しない機能境界と
> 第3節の小数字句だけを上書きします。正確な小数値と固定小数点表示は変更しません。

## 1. 範囲と機能境界

NUM機能グループでは、実行可能な正確な10進小数、整数の床除算と剰余、小数除算、5種類の丸め方法、絶対値、最小値、最大値、符号・範囲操作、最大公約数・最小公倍数、非負整数乗、偶奇判定、桁指定丸め、整数と小数の明示変換、小数配列を追加します。

2進浮動小数、指数表記、複素数、有理数、初等関数、乱数、数式構文、暗黙の整数・小数変換は追加しません。文字列との数値変換はTEXT機能グループへ送ります。

## 2. 値型

### 2.1 整数

`整数`は従来どおり任意精度の符号付き整数です。符号を除く10進桁数は、演算結果について65,536桁以下でなければなりません。

### 2.2 小数

`小数`は、符号つき10進係数`c`と整数スケール`s`からなる正確な値です。

```text
値 = c × 10^(-s)
```

実行時の小数値は次の正規形で保持します。

- 0は`c = 0`、`s = 0`とする
- 0以外の`c`は10で割り切れない
- 係数の符号を除く桁数を有効桁数とする。0の有効桁数は1とする
- 有効桁数は65,536以下、`s`の絶対値は65,536以下とする
- 負の0と、表示情報としてだけの末尾0は保持しない

したがって`1.0`、`1.00`、`1`から明示変換した小数は、型は小数のまま同じ数値です。Java実装では`BigDecimal`を使用できますが、`equals`ではなく数値比較に相当する意味を公開します。

### 2.3 丸め方法

`丸め方法`は次の5個だけを値に持つ具体型です。

| 値 | 意味 |
|---|---|
| `最近接偶数丸め` | 最も近い値。中間は末尾が偶数になる方 |
| `四捨五入` | 最も近い値。中間は0から遠い方 |
| `0方向へ丸め` | 0へ近づく方向 |
| `正方向へ丸め` | 正の無限大方向 |
| `負方向へ丸め` | 負の無限大方向 |

5個は組み込み値で、再定義できません。同じ値どうしを`等しい`で比較でき、表示すると正規名になります。

### 2.4 型制約

辞書内の`N`は`整数`または`小数`の同じ具体型、`数値`は各入力位置で独立に`整数`または`小数`を受理する型集合です。利用者定義単語のスタック効果には`N`と`数値`を書けません。

加減乗、比較、絶対値、最小値、最大値は`N`を使い、整数と小数を混在させません。`小数で割る`と`精度指定で割る`だけは、単語自身の意味として各数値入力を正確な小数へ持ち上げるため、4通りの整数・小数組合せを受理します。これは代入や他の単語へ伝播する暗黙変換ではありません。

## 3. 小数リテラルと値の表示

小数リテラルの字句はD-030を引き継ぎます。ASCII数字、小数点の前後1桁以上、指数表記なし、符号と小数点を除く最大4,096桁です。

`check`と`run`はCORE機能グループの`E_FEATURE_NOT_AVAILABLE`を解除し、字句から正規化した小数値を作ります。`format`は[numerics-format.md](numerics-format.md)のとおり元の有効な字句を保持します。

小数値の表示とトレース元文字列は次の一意な形です。

- ASCIIの符号付き固定小数点表記とし、指数を使わない
- 正数へ`+`を付けず、整数部を必ず1桁以上出す
- 小数点を必ず含める
- 小数部の不要な末尾0を出さない
- 数学的に整数なら小数部を`.0`とする
- 0は`0.0`とし、負の0を出さない

例は`0.0`、`1.23`、`-0.005`、`1200.0`です。

## 4. 同型の正確な演算

既存単語を次へ拡張します。

```text
足す             （N N -- N）
引く             （N N -- N）
掛ける           （N N -- N）
比べて小さい     （N N -- 真偽）
```

整数どうしは従来の意味を変えません。小数どうしの加算、減算、乗算は丸めず正確な結果を返してから正規化し、結果上限を検査します。小数の比較はスケールではなく数学的な値を比較します。

次の単語を追加します。

```text
絶対値           （N -- N）
最小値           （N N -- N）
最大値           （N N -- N）
```

`最小値`と`最大値`は等しい入力なら第1入力と同じ値を返すものとして扱えますが、値の同一性は観測できません。

### 4.1 符号と範囲

```text
符号を得る          （N -- 整数）
範囲内に収める      （N N N -- N）
```

`符号を得る`は負・0・正に対してそれぞれ`-1`、`0`、`1`を返します。`範囲内に収める`の入力順は値、下限、上限です。値が下限未満なら下限、上限超過なら上限、それ以外なら値を返します。3入力は同じ数値型でなければならず、下限が上限より大きい場合は`E_NUMERIC_RANGE_INVALID`です。

### 4.2 整数論と累乗

```text
最大公約数          （整数 整数 -- 整数）
最小公倍数          （整数 整数 -- 整数）
整数乗する          （N 整数 -- N）
```

最大公約数と最小公倍数は常に非負です。`最大公約数(0, 0)`と、いずれかの入力が0である最小公倍数は0です。

`整数乗する`は第1入力を底、第2入力を指数とし、丸めず正確に計算します。指数は0以上でなければならず、すべての底について0乗は1なので`0^0`も1です。整数底は整数、小数底は小数を返します。負の指数は`E_NEGATIVE_EXPONENT`、結果上限超過は既存の整数・小数結果診断です。

### 4.3 偶奇判定と桁指定丸め

```text
偶数である          （整数 -- 真偽）
奇数である          （整数 -- 真偽）
小数桁で丸める      （小数 整数 丸め方法 -- 小数）
有効桁で丸める      （小数 整数 丸め方法 -- 小数）
```

0は偶数です。負の整数も絶対値と同じ偶奇を持ちます。`小数桁で丸める`の桁数は小数点以下の桁数で0〜65,536、`有効桁で丸める`の桁数は先頭の0でない数字から数える有効桁数で1〜65,536です。範囲外は`E_ROUNDING_DIGITS_OUT_OF_RANGE`です。結果は通常の小数正規形へ戻すため、表示用の末尾0は保持しません。`少数桁で丸める`は`小数桁で丸める`の別名です。

## 5. 整数の床除算と剰余

```text
割った商          （整数 整数 -- 整数）
割った剰余        （整数 整数 -- 整数）
割った商と剰余    （整数 整数 -- 整数 整数）
```

第1入力が被除数、第2入力が除数です。商は負の無限大方向へ丸める床除算です。剰余は0であるか、除数と同じ符号を持ち、常に次を満たします。

```text
被除数 = 商 × 除数 + 剰余
```

`割った商と剰余`は商、その上に剰余を積むため、実行直後の最上部は剰余です。

| 被除数 | 除数 | 商 | 剰余 |
|---:|---:|---:|---:|
| `10` | `3` | `3` | `1` |
| `-10` | `3` | `-4` | `2` |
| `10` | `-3` | `-4` | `-2` |
| `-10` | `-3` | `3` | `-1` |

除数0は`E_DIVISION_BY_ZERO`です。

## 6. 小数除算

```text
小数で割る        （数値 数値 -- 小数）
精度指定で割る    （数値 数値 整数 丸め方法 -- 小数）
```

第1入力が被除数、第2入力が除数です。整数入力は値を失わず正確な小数へ変換してから計算します。

`小数で割る`は有効桁数28、`最近接偶数丸め`を使います。`精度指定で割る`の第3入力は1以上4,096以下の有効桁数です。指定桁数は小数点以下の桁数ではありません。有限桁で正確に表せる結果は不要な0で指定精度まで埋めません。

```text
10 と 3 を 小数で割る
# 3.333333333333333333333333333

1 と 8 と 2 と 最近接偶数丸め で 精度指定で割る
# 0.12
```

除数が整数0、`0.0`、`-0.0`のいずれでも`E_DIVISION_BY_ZERO`です。

## 7. 明示変換と整数丸め

```text
小数に変換する    （整数 -- 小数）
整数に変換する    （小数 -- 整数）
整数に丸める      （小数 丸め方法 -- 整数）
```

`小数に変換する`は値を失いません。`整数に変換する`は小数部が数学的に0の場合だけ成功し、それ以外は`E_DECIMAL_NOT_INTEGER`です。切り捨てを暗黙に行いません。

`整数に丸める`は小数点位置で指定方法を適用します。結果は`整数`で、整数結果の65,536桁上限を受けます。

| 入力 | 方法 | 結果 |
|---:|---|---:|
| `2.5` | `最近接偶数丸め` | `2` |
| `3.5` | `最近接偶数丸め` | `4` |
| `-2.5` | `四捨五入` | `-3` |
| `-2.9` | `0方向へ丸め` | `-2` |
| `-2.1` | `正方向へ丸め` | `-2` |
| `-2.1` | `負方向へ丸め` | `-3` |

## 8. 等価性と表示可能性

`等しい`へ`小数`と`丸め方法`を追加します。小数は正規化前のスケールや字句ではなく数値で比較するため、`1.0`と`1.00`は等しい値です。整数`1`と小数`1.0`は異なる型なので静的な`E_TYPE_MISMATCH`です。

`表示可能`へ`小数`と`丸め方法`を追加します。出力は第3節と第2.3節の正規表記を使い、既存の64 MiB上限に対して呼出し単位で原子的に検査します。

## 9. 小数配列

NUM機能グループでは`小数`を1次元配列の要素型へ追加します。

```text
配列<小数>
空の小数配列      （-- 配列<小数>）
【1.5、2.0、3.25】
```

整数と小数が混在する配列リテラルを暗黙変換せず、`E_ARRAY_ELEMENT_TYPE_MISMATCH`にします。必要なら各整数要素式で`小数に変換する`を明記します。

`丸め方法`は配列要素型にしません。`配列<丸め方法>`は`E_ARRAY_ELEMENT_TYPE_NOT_ALLOWED`です。多次元配列、異種配列、可変配列は引き続き後段です。

既存の配列操作、反復、不変性、構造的等価性、表示、長さ・構築・処理上限を小数配列にもそのまま適用します。

## 10. 実行とIR

小数リテラルと丸め方法値は、型付きの不変な実行時値として`PushConst`へ格納できます。数値演算は組み込み辞書で呼出しごとの具体的スタック効果へ解決し、IRには`数値`や`N`を残しません。

検査済みIRの実行器はJavaのクラスキャスト失敗、`ArithmeticException`、不正な丸め値を利用者エラーとして推測しません。合成不正IRは従来どおり内部エラー終了コード70です。

## 11. トレース

NUM機能グループもARRAY機能グループの21列を変更しません。小数は`小数:<正規表示>`、丸め方法は`丸め方法:<正規名>`です。非配列値は既存どおり値部分の先頭32 Unicodeコードポイントまで、配列は先頭8要素までを表示します。

小数配列の各要素は正規小数表記を使います。トレース用省略と非開示は演算結果、診断、資源判定へ影響しません。
