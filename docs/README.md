# BSB ドキュメント

このディレクトリには、BSB を学ぶ人、日常的に使う人、処理系を実装する人に向けた公開ドキュメントを置きます。
目的に合う入口から読み始めてください。

## BSB を学ぶ

- [言語チュートリアル](tutorial/README.md): 初めての実行から、単語、制御構文、データ、任意・結果、診断、HTTP API、CSV/TSVまでを順番に学ぶ
- [サンプル集](../samples/README.md): 独立して実行できるプログラムから学ぶ

## 書き方を調べる

- [言語リファレンスマニュアル](reference/README.md): 構文、型、宣言、制御構文、組み込み語、実行環境をカテゴリ別に探す
- [言語仕様の概説](language-overview.md): 言語全体と、現在の対応範囲を短く把握する

## 言語と処理系を実装する

- [目的と設計原則](vision.md): BSB が目指すもの、AIとの相性、設計上の非目標
- [実行基盤の構成](runtime-architecture.md): 解析・IR・実行環境・公開JSONの境界
- [実装・配布ガイド](implementation-guide.md): ビルド、テスト、資源上限、CLI
- [機能グループと適合性テスト](conformance.md): 安定 ID、テスト配置、N/F/R の意味
- [詳細言語仕様](spec/README.md): 機能グループ別の規範、診断、整形、適合性仕様

リファレンスマニュアルは利用者が素早く調べるための案内です。厳密な境界、診断の優先順位、資源上限、
適合性要件は詳細言語仕様を正とします。日付、実装順、引き継ぎ記録は公開仕様へ混在させません。
