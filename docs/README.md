# BSB ドキュメント

このディレクトリには、BSB を初めて読む利用者と実装者に向けた公開ドキュメントを置きます。
過去の開発順ではなく、現在利用できる機能とその契約を基準に構成します。

- [最小言語仕様の概説](language-overview.md): 構文、型、実行、外部能力、制限の全体像
- [目的と設計原則](vision.md): BSB が目指すもの、AIとの相性、設計上の非目標
- [実行基盤の構成](runtime-architecture.md): 解析・IR・実行環境・公開JSONの境界
- [実装・配布ガイド](implementation-guide.md): ビルド、テスト、資源上限、CLI
- [機能グループと適合性テスト](conformance.md): 安定 ID、テスト配置、N/F/R の意味
- [詳細言語仕様](spec/README.md): 機能グループ別の規範、診断、整形、適合性仕様

詳細な規範文書も、ここで定義する機能グループ ID を使用します。日付、実装順、引き継ぎ記録は
公開仕様へ混在させません。
