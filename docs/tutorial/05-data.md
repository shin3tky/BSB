# 5. 配列と文字列

この章では、複数の値をまとめて扱う配列と、文字列の基本を学びます。JSON は次の章で扱います。

## 配列を作り、要素を取り出す

```text
色は 定数 【「赤」、「青」、「緑」】。
```

配列の要素は同じ型でなければなりません。添字は0から始まるので、最初の要素の添字は0、2番目は1です。

```text
色 を 配列の長さ                    # 3
色 と 0 を 配列から取り出す          # 「赤」
色 と 0 と 2 を 配列の一部を取り出す # 【「赤」、「青」】
```

`配列の一部を取り出す` の範囲は、開始を含み終了を含まない半開区間です。上の `0` と `2` は、添字0から
添字2の直前までを意味します。存在しない添字を指定すると実行時に診断が出るため、長さが分からない配列の先頭や
末尾には、`配列の先頭を任意で取り出す` と `配列の末尾を任意で取り出す` を使えます。

空の配列は要素から型を決められないため、`空の整数配列` や `空の文字列配列` のような型ごとの単語で作ります。

## 要素を追加、挿入、削除する

配列は不変です。配列操作は元の配列を書き換えず、新しい配列を返します。変数の内容を更新したい場合は、返された
配列を同じ変数へ入れます。

```text
買い物は 変数 【「りんご」、「卵」】。

メインとは （--）
    買い物 と 「パン」 を 配列の末尾へ追加する を 買い物 に 入れる
    買い物 と 1 と 「牛乳」 を 配列の位置へ挿入する を 買い物 に 入れる
    買い物 と 0 を 配列の位置を削除する を 買い物 に 入れる
    買い物 を 一行表示する
こと。
```

実行結果は `【「牛乳」、「卵」、「パン」】` です。`配列の位置へ挿入する` は指定位置にあった要素の直前へ
追加します。末尾追加のほか、先頭への追加、要素の置換、先頭・末尾・範囲の削除もできます。

| やりたいこと | 使う単語 |
|---|---|
| 末尾または先頭へ1要素を足す | `配列の末尾へ追加する`、`配列の先頭へ追加する` |
| 指定位置へ1要素を入れる | `配列の位置へ挿入する` |
| 指定位置の値を変える | `配列の要素を置き換える` |
| 1要素または範囲を消す | `配列の位置を削除する`、`配列の一部を削除する` |
| 2つの配列をまとめる | `配列をつなぐ` |

## 値を探し、整理する

```text
【「赤」、「青」、「赤」、「緑」】 と 「青」 を 配列に含まれる       # はい
【「赤」、「青」、「赤」、「緑」】 と 「赤」 を 配列から検索する     # 0
【「赤」、「青」、「赤」、「緑」】 と 「赤」 を 配列内の個数を数える # 2
【「赤」、「青」、「赤」、「緑」】 を 配列の重複を除く              # 【「赤」、「青」、「緑」】
```

`配列から検索する` は最初に見つかった添字を返し、見つからなければ `-1` を返します。2個目以降も探す場合は
`開始位置から配列を検索する` を使います。`配列の重複を除く` は、それぞれの値が最初に現れた順序を保ちます。

同じ初期値を指定個数だけ並べたいときは、`同じ値で配列を作る` を使います。

```text
0 と 5 を 同じ値で配列を作る # 【0、0、0、0、0】
```

配列の全要素を順番に処理するには、前章で学んだ `各要素について` を使います。すべての配列操作と正確な入力順は
[組み込み単語カタログ](../reference/builtin-catalog.md#一次元配列array)で確認できます。

## Unicode 文字列

```text
「  BSBで日本語プログラミング  」 を 前後の空白を除く
「赤,青,緑」 と 「,」 を 文字列を分割する
「Hello, World!」 と 「World」 と 「BSB」 を 文字列を置き換える
```

`文字列の長さ` や、文字列の一部を取り出す単語は、人が1文字と感じる単位（拡張書記素クラスタ）で数えます。Unicode の
コードポイント単位で処理したい場合は、名前に `コードポイント` を含む単語を明示的に使います。

正規表現は `正規表現「…」` と書き、完全一致、部分一致、名前付きグループの取出し、置換、分割に使えます。

## 試してみよう

整数配列 `得点` を `【70、80】` で作り、末尾へ90を追加して変数を更新してください。次に、添字0の値を75へ
置き換えてから、`各要素について` で1行ずつ表示してみましょう。

<summary>回答例</summary>

```text
得点は 変数 【70、80】。

メインとは （--）
    得点 と 90 を 配列の末尾へ追加する を 得点 に 入れる
    得点 と 0 と 75 を 配列の要素を置き換える を 得点 に 入れる
    得点 を 各要素について
        一行表示する
    繰り返す
こと。
```

実行結果は次のとおりです。

```text
75
80
90
```

どちらの配列操作も新しい配列を返すため、`を 得点 に 入れる` で更新後の値を保存しています。
