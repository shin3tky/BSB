# 5. 配列、文字列、JSON

この章では、複数の値と外部データを扱う基本を学びます。

## 不変の配列

```text
色は 定数 【「赤」、「青」、「緑」】。
```

配列の要素は同じ型でなければなりません。添字は0から始まり、範囲指定は開始を含み終了を含まない
半開区間です。

```text
色 と 0 を 配列から取り出す          # 「赤」
色 と 0 と 2 を 配列の一部を取り出す # 【「赤」、「青」】
色 を 配列の長さ                    # 3
```

配列は不変です。`配列の要素を置き換える` や `配列の末尾へ追加する` は元の配列を変更せず、新しい配列を
返します。空配列は要素型を推論できないため、`空の整数配列` など型ごとの組み込み値を使います。

## Unicode 文字列

```text
「  BSBで日本語プログラミング  」 を 前後の空白を除く
「赤,青,緑」 と 「,」 を 文字列を分割する
「Hello, World!」 と 「World」 と 「BSB」 を 文字列を置き換える
```

通常の `文字列の長さ` や取出しは、人が1文字と感じる拡張書記素クラスタを基準にします。Unicode の
コードポイント単位で処理したい場合は、名前に `コードポイント` を含む単語を明示的に使います。

正規表現は `正規表現「…」` と書き、完全一致、部分一致、名前付き部分の取出し、置換、分割に使えます。

## JSON は文字列から解析する

BSB のソースへ JSON リテラルを直接書く構文はありません。文字列を解析します。

```text
注文は 変数 JSONヌル。

メインとは （--）
    「{"orderId":"A-100","quantity":2}」 を JSONを解析する
    を 注文 に 入れる
    注文 と 「orderId」 を JSONオブジェクトから必須値を取り出す
    JSONから文字列を取り出す
    一行表示する
こと。
```

`JSONを解析する` は、信頼済みで必ず正しい入力に便利です。不正な JSON も通常の処理として扱いたい場合は、
`JSONを解析して結果を返す` を使います。

## JSONの構造をまとめて検証する

外部JSONの必須キーや値種類を一度に確かめるには`JSON形状`を組み立てます。次は`orderId`を必須文字列、
`note`を欠落可能かつnull許容の文字列として検証します。

```text
注文
空のJSONオブジェクト形状
「orderId」 と JSON文字列の形状
JSON形状に必須キーを設定する
「note」 と JSON文字列の形状
JSON形状をヌル許容にする
JSON形状に任意キーを設定する
JSONの形状を検証する
```

戻り値は`結果<JSON,配列<JSON形状失敗>>`です。失敗側は形状の設定順で並び、専用語から失敗種類、
JSON Pointer path、期待種類、実際種類を取得できます。形状に書かなかったキーは許可されます。

## 入れ子JSONの参照とオブジェクト構築を短くする

固定した入れ子位置をたどる場合は、RFC 6901 JSON Pointerを使えます。対象がない場合は診断終了せず、
`任意<JSON>`の値なしになります。JSON nullは値ありとして区別されます。

```text
応答 と 「/response/items/0/id」 を JSONをポインターで任意参照する
```

キーと値がすでに配列で揃っている場合は、不変オブジェクトを一度に作れます。

```text
【「model」、「stream」】 と
【「gpt-example」を 文字列をJSONに変換する、いいえ を 真偽をJSONに変換する】 を
JSONオブジェクトを構築する
```

## 値がない可能性は `任意`

オブジェクトのキーがないことを許したい場合は `JSONオブジェクトから任意値を取り出す` を使います。
結果は `任意<JSON>` です。

```text
設定 と 「mode」 を JSONオブジェクトから任意値を取り出す
任意に値がある ならば
    任意から値を取り出す
    JSONを文字列に変換する
    一行表示する
さもなければ
    任意を捨てる
    「未設定」 を 一行表示する
つぎに
```

判定単語は後の分岐でも元の任意値を使えるよう、`任意` と `真偽` の両方を残します。値なし側では
`任意を捨てる` ことを忘れないでください。

## 失敗する可能性は `結果`

`結果<T,E>` は成功値 `T` または失敗値 `E` のどちらかを持ちます。`結果が成功である` で判定し、
成功側は `結果から成功値を取り出す`、失敗側は `結果から失敗値を取り出す` で中身を得ます。

JSON の回復可能解析、UTF-8・Base64 復号、HTTPS、ファイル、CSV/TSV は結果値を返します。入力の誤りは
分岐で処理できる一方、資源上限超過や実行環境能力の不足は診断として実行を終了します。

## 試してみよう

文字列の配列を作り、`各要素について` で1行ずつ表示してみましょう。次に、空の JSON オブジェクトへ
`name` キーを設定し、JSON 文字列として表示してみましょう。

<details>
<summary>回答例</summary>

```text
メインとは （--）
    【「赤」、「青」、「緑」】 を 各要素について
        一行表示する
    繰り返す

    空のJSONオブジェクト
    と 「name」
    と 「BSB」 を 文字列をJSONに変換する
    JSONオブジェクトに設定する
    JSONを文字列に変換する
    一行表示する
こと。
```

実行結果は次のとおりです。

```text
赤
青
緑
{"name":"BSB"}
```

配列ループでは、各反復の入口に現在の文字列が1個積まれ、`一行表示する` がそれを消費します。
JSON の設定操作は元の空オブジェクトを変更せず、`name` を持つ新しい JSON オブジェクトを返します。

</details>
