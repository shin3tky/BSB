# 2. 値の流れと単語

BSB の処理は、値を積むことと「単語」を呼び出すことの組み合わせです。この値の置き場所を
データスタックと呼びます。

## 値を積み、単語で使う

次の1行を左から順に見てみます。

```text
6 と 7 を 掛ける 一行表示する
```

値の流れは次のようになります。

```text
6              [6]
7              [6, 7]
掛ける         [42]
一行表示する   []
```

`掛ける` は2個の数値を取り出し、積を1個積みます。`一行表示する` はその値を取り出して表示します。
助詞の `と` と `を` はスタックを変えません。

入力は、単語の直前に置かれた順にスタックへ積まれます。たとえば `引く` では先に置いた値が左辺です。

```text
100 と 58 を 引く   # 42
```

## スタック効果を読む

単語が受け取る型と返す型を、スタック効果で表します。

```text
掛ける          （N N -- N）
等しい          （T T -- 真偽）
一行表示する    （表示可能 --）
```

`--` の左側が入力、右側が出力です。`N` は同じ数値型、`T` は同じ型、`表示可能` は表示できる型を示す
辞書上の記号です。利用者が定義する単語の宣言には、`整数` や `文字列` などの具体的な型を書きます。

BSB は実行前に、必要な値が足りているか、型が合っているか、最後に残る値が宣言と一致するかを検査します。

## 自分の単語を作る

12を受け取り144を返すのではなく、どの整数にも使える `二乗` を定義します。

```text
二乗とは （整数 -- 整数）
    数は 変数 0。
    を 数 に 入れる
    数 と 数 を 掛ける
こと。

メインとは （--）
    12 を 二乗
    一行表示する
こと。
```

定義の入口では、宣言した入力がすでにスタックにあります。ここでは入力を局所変数 `数` へ保存し、
2回読み出して掛けています。単語の終わりには `整数` が1個残るため、宣言した出力と一致します。

単語は定義より前から呼ぶことができ、自分自身を呼ぶ再帰も可能です。ただし `メイン` は入口専用で、
ほかの単語からは呼べません。

## 型は暗黙に変わらない

整数 `2` と小数 `2.0` は別の型です。必要なら明示的に変換します。

```text
2 を 小数に変換する   # 小数 2
2.5 と 四捨五入 で 整数に丸める   # 整数 3
```

暗黙変換を行わないため、処理の途中でどの型を扱っているかを追いやすくなっています。

## 試してみよう

整数を1個受け取り、3倍した整数を返す `三倍` を定義してみましょう。`メイン` から `14` を渡すと
`42` が表示されるようにします。

<details>
<summary>回答例</summary>

```text
三倍とは （整数 -- 整数）
    3 を 掛ける
こと。

メインとは （--）
    14 を 三倍
    一行表示する
こと。
```

`三倍` の入口には、呼出し側から渡された `14` がすでにあります。`3` を積んで `掛ける` と、
2個の整数を消費して `42` が1個残ります。これは宣言した `（整数 -- 整数）` と一致します。

</details>
