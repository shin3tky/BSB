# 3. 名前を付ける

何度も使う値には `定数`、途中で更新する値には `変数` で名前を付けます。

## 定数と変数

```text
税率は 定数 0.10。
合計は 変数 0。
```

宣言は `名前は` と続けて書き、`。` で終えます。初期値から型が決まります。この例では `税率` は
`小数`、`合計` は `整数` です。

宣言した名前を書くと、その現在の値がスタックへ積まれます。

```text
合計 を 一行表示する
```

単語の外で宣言した名前（大域名）は、どの単語からも参照できます。単語や制御ブロックの中で宣言した名前（局所名）は、
その範囲の中だけで使えます。

## 変数へ代入する

```text
現在の数は 変数 1。

メインとは （--）
    現在の数 と 1 を 足す を 現在の数 に 入れる
    現在の数 を 一行表示する
こと。
```

`を 名前 に 入れる` は、スタックの先頭値を指定した変数へ保存します。代入した値はスタックに残りません。
定数へは代入できず、変数へ宣言時と異なる型の値を入れることもできません。

## 単語の入力に名前を付ける

BSB の単語定義には、入力へ直接名前を付ける構文がありません。名前で扱いたい場合は、入口のスタックにある値を
局所変数へ1個ずつ保存します。

```text
長方形の面積とは （整数 整数 -- 整数）
    高さは 変数 0。
    幅は 変数 0。
    を 高さ に 入れる
    を 幅 に 入れる
    幅 と 高さ を 掛ける
こと。
```

`10 と 4 を 長方形の面積` と呼ぶと、入口のスタックは `[10, 4]` です。最初の代入は先頭の `4` を
`高さ` へ、次の代入は `10` を `幅` へ保存します。

入力が複数あるときは、最後の入力（スタックの先頭）から逆順に変数へ保存すると覚えてください。

## 宣言の範囲

局所名は宣言した直後から、その単語本体または制御ブロックの末尾まで有効です。内側で外側と同じ名前を
宣言することはできません（`E_NAME_SHADOWING` エラー）。これにより、ある名前がどの宣言を指すかが常に明確になります。

初期値の式で使えるのは、すでに初期化された名前と、副作用のない一部の組み込み単語だけです。画面出力や
利用者定義単語の呼び出しは初期値には書けません。

## 試してみよう

大域変数 `得点` を0で宣言し、`10` を加えた値を `得点` へ保存してから表示するプログラムを書いてみましょう。

<details>
<summary>回答例</summary>

```text
得点は 変数 0。

メインとは （--）
    得点 と 10 を 足す を 得点 に 入れる
    得点 を 一行表示する
こと。
```

実行結果は次のとおりです。

```text
10
```

`足す` が返した値は、`を 得点 に 入れる` によってスタックから取り出され、変数へ保存されます。
その後に `得点` を参照すると、更新後の値がスタックへ積まれます。

</details>
