# 6. JSON を扱う

JSON は、HTTP API や設定ファイルなど、BSB の外部と構造化されたデータを受け渡すときによく使います。この章では
JSON 文字列の解析、値の取出し、構造の検証、オブジェクトの作成を学びます。

## JSON は文字列から解析する

BSB のソースへ JSON リテラルを直接書く構文はありません。文字列を解析します。

```text
注文は 変数 JSONヌル。

メインとは （--）
    「{"orderId":"A-100","quantity":2}」 を JSONを解析する
    を 注文 に 入れる
    注文 と 「orderId」 を JSONオブジェクトから必須値を取り出す
    JSONから文字列を取り出す
    一行表示する
こと。
```

`JSONを解析する` は、入力が不正な JSON だと診断を出して実行を終了します。内容が正しいと分かっている入力に使います。
外部から受け取った JSON のように、不正な場合も処理を続けたいときは、`JSONを解析して結果を返す` を使います。

## 値がない可能性は `任意`

オブジェクトのキーがないことを許したい場合は `JSONオブジェクトから任意値を取り出す` を使います。結果は
`任意<JSON>` です。

```text
設定 と 「mode」 を JSONオブジェクトから任意値を取り出す
任意に値がある ならば
    任意から値を取り出す
    JSONを文字列に変換する
    一行表示する
さもなければ
    任意を捨てる
    「未設定」 を 一行表示する
つぎに
```

`任意に値がある` は、分岐の後でも元の値を使えるように、`任意` をスタックに残したまま `真偽` を積みます。
そのため、値なし側でも `任意を捨てる` で `任意` を取り除く必要があります。

## 失敗する可能性は `結果`

`JSONを解析して結果を返す` の戻り値は `結果<JSON,JSON解析失敗>` です。`結果が成功である` で判定し、
成功側は `結果から成功値を取り出す`、失敗側は `結果から失敗値を取り出す` で中身を得ます。

`結果<T,E>` は成功値 `T` または失敗値 `E` のどちらかを持つ型です。次章では `任意` と `結果` を使った
処理をさらに短く組み立てる方法を学びます。

## JSON の構造をまとめて検証する

外部から受け取った JSON の必須キーや値の種類をまとめて確かめるには、`JSON形状` を組み立てます。次の例では、
`orderId` を必須の文字列、`note` を省略可能で null も許す文字列として検証します。

```text
注文
空のJSONオブジェクト形状
「orderId」 と JSON文字列の形状
JSON形状に必須キーを設定する
「note」 と JSON文字列の形状
JSON形状をヌル許容にする
JSON形状に任意キーを設定する
JSONの形状を検証する
```

`JSONの形状を検証する` の戻り値は `結果<JSON,配列<JSON形状失敗>>` です。失敗側の配列は、形状にキーを設定した順に
並びます。各要素からは、専用の取出し単語で失敗の種類、JSON Pointer 形式のパス、期待した種類、実際の種類を
取得できます。形状に設定していないキーが入力にあっても、失敗にはなりません。

## 入れ子の JSON を参照する

決まった位置にある入れ子の値を取り出すときは、RFC 6901 の JSON Pointer（`/response/items/0/id` のような
経路文字列）を使えます。指定した位置に値がなくても実行は終了せず、結果は `任意<JSON>` の値なしになります。
値が JSON の null の場合は、値なしではなく、null を持つ値ありになります。

```text
応答 と 「/response/items/0/id」 を JSONをポインターで任意参照する
```

## JSON オブジェクトを作る

空の JSON オブジェクトへ、キーと JSON 値を設定できます。設定操作も配列操作と同じく元の値を変更せず、新しい
JSON オブジェクトを返します。

```text
空のJSONオブジェクト
と 「name」
と 「BSB」 を 文字列をJSONに変換する
JSONオブジェクトに設定する
```

キーの配列と値の配列がすでにある場合は、`JSONオブジェクトを構築する` で一度に作れます。2つの配列の要素は、
同じ位置どうしがキーと値として対応します。

```text
【「model」、「stream」】 と
【「gpt-example」 を 文字列をJSONに変換する、いいえ を 真偽をJSONに変換する】 を
JSONオブジェクトを構築する
```

この例は `{"model":"gpt-example","stream":false}` という JSON オブジェクトを作ります。

## 試してみよう

空の JSON オブジェクトへ `name` キーと文字列値 `BSB` を設定し、JSON 文字列として表示してみましょう。
