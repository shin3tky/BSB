# BSB 言語チュートリアル

このチュートリアルは、BSB やスタック言語を初めて使う人のための入門教材です。上から順に進めると、
小さなプログラムを読み書きし、エラーを自分で直せるところまで到達します。

## 学習の進め方

各章のコードはリポジトリのルートで試します。まだ取得していない場合は、先に
[最初のプログラム](01-first-program.md)の準備を行ってください。

1. [最初のプログラム](01-first-program.md) — 実行、検査、整形を試す
2. [値の流れと単語](02-stack-and-words.md) — スタックと `（入力 -- 出力）` を理解する
3. [名前を付ける](03-bindings.md) — 定数、変数、代入を使う
4. [処理を分け、繰り返す](04-control-flow.md) — 条件分岐と3種類の反復を使う
5. [配列、文字列、JSON](05-data.md) — まとまったデータを扱う
6. [エラーを読み、次へ進む](06-errors-and-next-steps.md) — 診断とリファレンスを活用する

1章ずつコードを実行し、数値や文字列を少し変えて結果を確かめるのがおすすめです。章の最後にある
「試してみよう」は、すぐ後に答えがなくても構いません。

## このチュートリアルの表記

- BSB のプログラムは `text` のコードブロックで示します。
- スタックは左を底、右を先頭として `[6, 7]` のように示します。
- `（整数 整数 -- 整数）` は、整数を2個受け取り整数を1個返すという意味です。
- `を`、`と`、`に`、`から`、`で` は読みやすさのための助詞です。値を増減させません。

すでに基本を知っていて、特定の書き方だけを確認したい場合は
[言語リファレンスマニュアル](../reference/README.md)へ進んでください。
