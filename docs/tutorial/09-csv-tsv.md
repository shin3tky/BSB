# 10. CSV/TSV を扱う

BSB は CSV/TSV を、`配列<配列<文字列>>` として扱います。外側の配列が行、内側の配列がセルです。
この章では、文字列を表として解析し、行を追加して、別の区切り形式へ変換します。

## CSV/TSV を表として解析する

`CSVを表として解析する` と `TSVを表として解析する` は、文字列を厳密に解析して `結果` を返します。
成功値は文字列の二次元配列です。

```text
CSV入力は 定数 「商品,個数\n"りんご,青森",3\nみかん,2\n」。

メインとは （--）
    CSV入力 を CSVを表として解析する
    結果が成功である ならば
        結果から成功値を取り出す
        各要素について
            各要素について
                一行表示する
            繰り返す
        繰り返す
    さもなければ
        結果から失敗値を取り出す
        区切りテキスト解析失敗の種類を取り出す
        一行表示する
    つぎに
こと。
```

CSV の `"りんご,青森"` は、引用符の内側にあるカンマも1つのセルに含める書き方です。この例の成功値は、
次の表になります。

```text
【【「商品」、「個数」】、【「りんご,青森」、「3」】、【「みかん」、「2」】】
```

TSV を読むときは入力中の区切りを `\t` にし、解析語を `TSVを表として解析する` に置き換えます。どちらも
先頭行を見出しとして特別扱いせず、すべてのセルを文字列として返します。数値として計算したいセルは、取り出した
あとで `文字列を整数に変換する` などを明示的に使います。

この例の行区切りは LF（`\n`）です。RFC 4180 で定義される CRLF（`\r\n`）に加え、実際のファイルで広く使われる
LF 単独と CR 単独も、CSV/TSV の入力では行区切りとして受理します。CRLF は2行ではなく、1つの行区切りとして
扱われます。

## 解析できない入力を扱う

外部から受け取った CSV/TSV は、引用符が閉じていなかったり、行ごとのセル数が違ったりすることがあります。
これらは実行を直ちに終了する診断ではなく、`結果` の失敗側で扱えます。

```text
メインとは （--）
    「商品,個数\nりんご」 を CSVを表として解析する
    結果が成功である ならば
        結果から成功値を取り出す
        一行表示する
    さもなければ
        結果から失敗値を取り出す
        区切りテキスト解析失敗の種類を取り出す
        一行表示する
    つぎに
こと。
```

この例では、2行目のセルが1個しかないため、種類 `columnCountMismatch` が表示されます。失敗値から位置を調べる
場合は、`区切りテキスト解析失敗の行を取り出す`、`区切りテキスト解析失敗の列を取り出す`、または0始まりの
UTF-8 バイト位置を返す `区切りテキスト解析失敗のバイト位置を取り出す` を使います。

解析では、空白を自動で取り除いたり、区切り文字を推測したりしません。CSV はカンマ、TSV はタブに固定され、
引用符の規則も厳密です。入力に BOM がある場合は文書先頭の1個だけが取り除かれます。

## 表を編集して CSV/TSV に変換する

解析後の表は通常の不変配列です。配列操作は元の値を変更せず、新しい表を返します。

```text
表は 定数 【【「商品」、「個数」】、【「りんご」、「3」】】。

メインとは （--）
    表 と 【「みかん」、「2」】 を 配列の末尾へ追加する
    表をTSVに変換する
    一行表示する
こと。
```

`表をCSVに変換する` と `表をTSVに変換する` は、必要なセルだけを引用し、行末を CRLF にそろえた決定的な
文字列を返します。出力には BOM を付けません。変換する表は、すべての行のセル数が同じ矩形でなければなりません。
行ごとのセル数が違う表や、セルを1つも持たない行は、変換時に診断されます。

ファイルと組み合わせるときは、次の順につなぎます。

```text
ファイルを読む → UTF-8文字列へ変換 → CSV/TSVを解析 → 配列操作
→ CSV/TSVへ変換 → UTF-8バイト列へ変換 → ファイルへ書く
```

この一連の処理は
[`samples/24-csv-tsv-files.bsb`](../../samples/24-csv-tsv-files.bsb)で確認できます。BSB のソースには OS の
パスを書かず、名前付き作業領域を介してファイルを読み書きします。詳しい実行方法は
[サンプル集](../../samples/README.md)を参照してください。

正確な引用符・改行・BOM の規則、解析失敗の種類、資源上限は
[CSV/TSV 仕様](../spec/delimited-tables.md)にまとまっています。
