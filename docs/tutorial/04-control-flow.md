# 4. 処理を分け、繰り返す

BSB には条件分岐、短絡論理、回数ループ、条件ループ、配列ループがあります。どの経路でも値の数と型が
矛盾しないことを、実行前に検査します。

## 条件分岐

次の例の `年齢` は、整数の変数とします。

```text
年齢 と 18 を 比べて小さい ならば
    「未成年です」 を 一行表示する
さもなければ
    「成人です」 を 一行表示する
つぎに
```

`ならば` はスタック先頭の `真偽` を取り出して使います。`はい` なら最初のブロック、`いいえ` なら
`さもなければ` 側を実行します。`いいえ` のときの処理が不要なら、`さもなければ` を省略できます。

`つぎに` の後へ進むすべての経路で、残る値の数と型が一致しなければなりません。片方の経路だけで値を積むと、
後続の処理が受け取る値を決められないためエラーになります。`さもなければ` を省略した場合も、`はい` 側だけで
値を積むとエラーです。

## 短絡する論理条件

`または` と `かつ` は、直前に積まれた `真偽` を左側の条件、`つぎに` までの処理を右側の条件として扱います。
`または` は左側が `いいえ` のときだけ、`かつ` は左側が `はい` のときだけ右側を評価します。次の例の
`利用可能である` と `代替手段がある` は、`真偽` を返す利用者定義単語とします。

```text
利用可能である または
    代替手段がある
つぎに
```

右側の処理は `真偽` を1個残す必要があります。全体の結果として `真偽` が1個スタックに残ります。右側が評価されなかった
場合、右側に書いた表示などの副作用は起きません。

## 決まった回数だけ繰り返す

```text
3 回だけ
    「こんにちは」 を 一行表示する
繰り返す
```

`回だけ` はスタック先頭の整数を1個取り出し、その回数だけ本体を実行します。0なら本体を実行せず、負数は
実行時エラーです。何回目の反復かを表す番号はスタックへ積まれないため、必要なら変数を用意して更新します。

## 条件が成り立つ間、繰り返す

```text
残りは 変数 3。

ここから
    0 と 残り を 比べて小さい
続く間
    残り を 一行表示する
    残り と 1 を 引く を 残り に 入れる
繰り返す
```

反復のたびに、`ここから` と `続く間` の間に書いた条件を評価します。結果が `はい` なら本体を実行し、`いいえ` に
なった時点でループを終えます。この例は `3`、`2`、`1` を順に表示します。

## 配列の各要素を処理する

```text
【72、85、90】 を 各要素について
    一行表示する
繰り返す
```

各反復の入口で、現在の要素がスタックに1個積まれます。本体はその要素を消費し、反復の出口ではスタックを
反復前と同じ状態に戻す必要があります。二次元配列を処理するときは、`各要素について` を入れ子にします。

## 途中で流れを変える

- `打ち切る` は最も内側のループを終了し、そのループの直後へ進みます。
- `続ける` は最も内側のループの次の反復へ進みます。
- `戻る` は現在の利用者定義単語から戻ります。

同じブロック内でこれらの後に書いた処理は実行されないため、処理系は警告（`W_UNREACHABLE_CODE`）を出します。
また、これらを実行する時点のスタックは、移動先で求められる値の数と型に一致していなければなりません。
たとえば `回だけ` の中では、回数を取り出した直後と同じスタックの形にしておきます。

## 試してみよう

1から5までを表示するプログラムを書いてみましょう。大域変数を1から始め、`5 回だけ` の本体で表示と
加算・代入を行います。

<details>
<summary>回答例</summary>

```text
現在の数は 変数 1。

メインとは （--）
    5 回だけ
        現在の数 を 一行表示する
        現在の数 と 1 を 足す を 現在の数 に 入れる
    繰り返す
こと。
```

実行結果は次のとおりです。

```text
1
2
3
4
5
```

`回だけ` は反復番号をスタックへ積みません。そのため、ここでは `現在の数` を自分で更新しています。
表示と代入はどちらも値をスタックに残さないので、各反復の出口でもスタックは空になり、反復前と同じ形になります。

</details>
