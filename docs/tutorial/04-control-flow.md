# 4. 処理を分け、繰り返す

BSB には条件分岐、短絡論理、回数ループ、条件ループ、配列ループがあります。どの経路でも値の数と型が
矛盾しないことを、実行前に検査します。

## 条件分岐

```text
年齢 と 18 を 比べて小さい ならば
    「未成年です」 を 一行表示する
さもなければ
    「成人です」 を 一行表示する
つぎに
```

`ならば` はスタック先頭の `真偽` を使います。`はい` なら最初のブロック、`いいえ` なら
`さもなければ` 側を実行します。偽側が不要なら `さもなければ` を省略できます。

両方の分岐が続く場合、分岐後に残る値の数と型は一致しなければなりません。片側だけで値を積むコードは、
後続処理がどの値を受け取るか決められないためエラーになります。

## 短絡する論理条件

`または` は左側が `いいえ` のときだけ、`かつ` は左側が `はい` のときだけ右側を評価します。

```text
利用可能である または
    代替手段がある
つぎに
```

右側は `真偽` を1個残す必要があります。評価されない右側の副作用は発生しません。

## 決まった回数だけ繰り返す

```text
3 回だけ
    「こんにちは」 を 一行表示する
繰り返す
```

`回だけ` は整数を1個使います。0なら本体を実行せず、負数は実行時エラーです。反復番号は自動では
渡されないため、必要なら変数を用意して更新します。

## 条件が成り立つ間、繰り返す

```text
残りは 変数 3。

ここから
    0 と 残り を 比べて小さい
続く間
    残り を 一行表示する
    残り と 1 を 引く を 残り に 入れる
繰り返す
```

`ここから` と `続く間` の間を毎回評価します。結果が `はい` の間だけ本体を実行します。

## 配列の各要素を処理する

```text
【72、85、90】 を 各要素について
    一行表示する
繰り返す
```

各反復の入口で、現在の要素がスタックに1個積まれます。本体はその要素を使い切り、反復前と同じ
スタック状態へ戻す必要があります。二次元配列ではループを入れ子にできます。

## 途中で流れを変える

- `打ち切る` は最も内側のループを終了します。
- `続ける` は最も内側のループの次の反復へ進みます。
- `戻る` は現在の利用者定義単語から戻ります。

これらの直後は到達不能になるため、処理系は警告を出します。移動する地点のスタックも、合流先が要求する
形と一致していなければなりません。

## 試してみよう

1から5までを表示するプログラムを書いてみましょう。大域変数を1から始め、`5 回だけ` の本体で表示と
加算・代入を行います。

<details>
<summary>回答例</summary>

```text
現在の数は 変数 1。

メインとは （--）
    5 回だけ
        現在の数 を 一行表示する
        現在の数 と 1 を 足す を 現在の数 に 入れる
    繰り返す
こと。
```

実行結果は次のとおりです。

```text
1
2
3
4
5
```

`回だけ` は反復番号をスタックへ積みません。そのため、ここでは `現在の数` を自分で更新しています。
表示と代入はどちらも値をスタックに残さないので、各反復の出口も空になり、ループ境界の条件を満たします。

</details>
