# 将来機能の設計ノート

このディレクトリには、現時点では導入しない機能について、将来の検討を始めるための論点を置きます。
ここにある文書は非規範であり、現在の構文、名前解決、診断、整形、IR、実行動作、公開 JSON 契約を
変更しません。実装済みの言語仕様は[詳細言語仕様](../spec/README.md)を正とします。

設計ノートに構文例や内部表現案があっても、予約語、診断コード、機能グループ ID を予約したことには
なりません。導入を決定した時点で、規範仕様、診断、整形、適合性テストを別途追加します。
