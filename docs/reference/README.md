## すぐに確認したい規則

- プログラムの入口は `メインとは （--） ... こと。` です。
- 評価順は左から右で、値はデータスタックへ積まれます。
- 単語の効果は `（入力型... -- 出力型...）` と書きます。
- 助詞 `を`、`に`、`と`、`から`、`で` はスタックを変えません。
- 整数、小数、文字、文字列などの間で暗黙の型変換は行いません。
- 配列、JSON、バイト列、HTTP要求は不変値です。更新操作は新しい値を返します。
- 添字は0始まり、slice の終端は含まない半開区間です。
- 分岐の合流点と反復の境界では、スタック上の値数と型が一致する必要があります。
- `任意`・`結果`の局所伝播は、現在の利用者定義単語からだけ早期復帰します。
- `任意<T>`と`結果<T,E>`は配列要素にでき、要素の具体型は完全に一致させます。
- HTTP送信の通信結果とHTTP statusの判定は別です。4xx・5xxも通信成功時は`HTTP応答`として返ります。

## 本書と詳細仕様の関係

本書は、利用時に必要な構文と代表的な操作をカテゴリ別にまとめます。すべての診断コード、資源上限、
判定順、整形規則、機械可読 JSON 契約は[詳細言語仕様](../spec/README.md)を正とします。
各ページの「詳細仕様」から対応する規範文書へ移動できます。

網羅性を確認するときは、処理系の組み込み辞書にある全語を機能グループ別に載せた
[全組み込み語一覧](builtin-catalog.md)を利用できます。詳細仕様の機能グループは、上の6カテゴリの
いずれかから到達できます。
