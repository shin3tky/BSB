# 組み込み語

組み込み語はカテゴリごとに探せます。各語は入力をスタックから取り出し、出力をスタックへ積みます。
正確な入力型・出力型、失敗条件、資源上限はリンク先の詳細仕様を参照してください。

全語のスタック効果を一度に確認する場合は、[全組み込み語一覧](builtin-catalog.md)を参照してください。

## 基本、比較、表示

| 単語 | スタック効果 | 動作 |
|---|---|---|
| `足す` | `（N N -- N）` | 同じ型の2数値を加える |
| `引く` | `（N N -- N）` | 第1数値から第2数値を引く |
| `掛ける` | `（N N -- N）` | 同じ型の2数値を掛ける |
| `等しい` | `（T T -- 真偽）` | 同じ型の2値を比較する |
| `比べて小さい` | `（N N -- 真偽）` | 第1数値が第2数値より小さいか調べる |
| `表示する` | `（表示可能 --）` | 改行せず標準出力へ表示する |
| `一行表示する` | `（表示可能 --）` | 表示して LF を出力する |
| `改行する` | `（--）` | LF を出力する |

`N`、`T`、`表示可能` は組み込み辞書だけで使う型制約です。利用者定義単語の宣言には書けません。

詳細: [基本組み込み語](../spec/language-core-builtins.md)、[数値](../spec/numerics.md)

| 数値変換・丸め | `小数に変換する`、`整数に変換する`、`整数に丸める`、`小数桁で丸める`、`有効桁で丸める` |
| 丸め方法 | `最近接偶数丸め`、`四捨五入`、`0方向へ丸め`、`正方向へ丸め`、`負方向へ丸め` |
| 空配列 | `空の小数配列` |

`足す`、`引く`、`掛ける`、`比べて小さい`、`絶対値`、`最小値`、`最大値`、`符号を得る`、`範囲内に収める`、`整数乗する`は整数または小数に使えますが、

## 任意値と結果値

| 用途 | 単語 |
|---|---|
| 任意値 | `任意にする`、`任意に値がある`、`任意から値を取り出す`、`任意を捨てる` |
| JSON の非必須キー | `JSONオブジェクトから任意値を取り出す` |
| 結果値の作成 | `成功にする<T,E>`、`失敗にする<T,E>` |
| 結果値の判定 | `結果が成功である`、`結果が失敗である` |
| 結果値の取出し | `結果から成功値を取り出す`、`結果から失敗値を取り出す`、`結果を捨てる` |

`成功にする` と `失敗にする` は、文脈だけで型を決められないときに型引数を名前の末尾へ付けます。
具体的な綴りは[結果値仕様](../spec/result-values.md)の「呼出し時の型引数」を参照してください。

`任意から値を取り出すか戻る`と`結果から成功値を取り出すか戻る`は組み込み語ではなく、利用者定義単語内の
局所伝播を表す制御構文です。値あり・成功なら中身を取り出し、値なし・失敗なら現在の単語から同種の
ラッパーを返します。詳しいスタック条件は[制御構文](control-flow.md#任意結果の局所伝播)を参照してください。

`任意<T>`と`結果<T,E>`は配列要素型にもできます。要素型の一致と入れ子上限は
[型と値](types-and-values.md#任意結果を要素に持つ配列)を参照してください。

詳細: [任意値](../spec/optional-values.md)、[結果値](../spec/result-values.md)、
[任意・結果の合成](../spec/optional-result-composition-diagnostics.md)

## 回復可能な JSON 解析

`JSONを解析して結果を返す` は `結果<JSON,JSON解析失敗>` を返します。失敗値からは
`JSON解析失敗の種類を取り出す`、`JSON解析失敗のバイト位置を取り出す`、`JSON解析失敗の行を取り出す`、
`JSON解析失敗の列を取り出す` で情報を取得できます。

詳細: [回復可能な JSON 解析](../spec/recoverable-json-parsing.md)

## 機械可読な完全一覧

現在の処理系が持つ全組み込み語は、任意の検査可能なプログラムに対する `explain --json` の
`builtinWords` から取得できます。名前、説明、スタック効果、型規則、能力、副作用、機能グループ、例を含みます。

```shell
java -jar build/libs/bsb-0.1.0-SNAPSHOT-all.jar explain --json samples/01-hello-world.bsb
```

この出力が組み込み語辞書の機械可読な正本です。
人間向けの[全組み込み語一覧](builtin-catalog.md)は、この `builtinWords` から生成しています。
