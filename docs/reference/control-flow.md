# 制御構文

## 条件分岐

```text
条件 ならば
    真の場合
さもなければ
    偽の場合
つぎに
```

条件は `真偽` を1個残します。`ならば` がその値を消費します。`さもなければ` は省略できます。
両側が通常終了する場合、出口のスタック形状は一致する必要があります。

## 短絡論理

```text
左の条件 または
    右の条件
つぎに

左の条件 かつ
    右の条件
つぎに
```

`または` は左が `いいえ` のとき、`かつ` は左が `はい` のときだけ右側を評価します。右側は `真偽` を
1個残します。評価しない右側の呼出し、副作用、実行予算消費は発生しません。

## 回数ループ

```text
回数 回だけ
    本体
繰り返す
```

回数は `整数` です。0なら0回、正数なら指定回数を実行し、負数は実行時診断になります。本体の通常終端と
`続ける`、`打ち切る` の地点は、回数を消費した直後と同じスタック形状にします。

## 条件ループ

```text
ここから
    条件を作る処理
続く間
    本体
繰り返す
```

条件計算部は各反復で実行され、`真偽` を1個残します。偽なら終了し、真なら本体へ進みます。

## 配列ループ

```text
配列 を 各要素について
    本体
繰り返す
```

各反復の入口で現在要素がスタックへ積まれます。本体は要素を消費し、ループ開始時と同じスタック形状へ
戻します。配列は先頭から末尾の順で処理されます。二次元配列はループを入れ子にして処理できます。

## 制御移行

| 構文 | 動作 | 使用できる場所 |
|---|---|---|
| `打ち切る` | 最も内側のループ直後へ進む | ループ内 |
| `続ける` | 最も内側のループの次反復へ進む | ループ内 |
| `戻る` | 現在の利用者定義単語から復帰する | 単語本体 |

制御移行の直後にある同じブロック内のコードは到達不能です。処理系はその範囲を実行せず、警告します。

## スタック合流

条件分岐や反復では複数の経路が同じ地点へ合流します。到達可能な各経路で、スタック上の値数と位置ごとの型が
完全に一致しなければなりません。片側だけに値を残したり、反復ごとに値を積み増したりするコードは拒否されます。
