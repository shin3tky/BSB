# 型と値

BSB は静的型付き言語です。実行前に各処理の入力と出力を検査し、異なる型を暗黙には変換しません。

## 基本型

| 型 | 値・用途 |
|---|---|
| `整数` | 任意精度の符号付き整数 |
| `小数` | 二進浮動小数へ変換しない正確な10進小数 |
| `真偽` | `はい` または `いいえ` |
| `文字` | Unicode の拡張書記素クラスタ1個 |
| `文字列` | Unicode 文字列 |
| `丸め方法` | 小数の除算・丸めで使う5種類の組み込み値 |
| `正規表現` | コンパイル済みの RE2 系正規表現 |
| `入力結果` | 入力行、入力終端、取消のいずれか |
| `日時` | エポックミリ秒と取得時 UTC オフセット |

整数と小数の加減乗算は、同じ型同士で行います。整数除算は `割った商` と `割った剰余`、小数除算は
`小数で割る` または `精度指定で割る` を使います。

## 複合型

| 型 | 内容 |
|---|---|
| `配列<T>` | 同じ具体型`T`を持つ不変配列。`T`には`任意`・`結果`も利用可能 |
| `配列<配列<T>>` | 行ごとの長さが異なってもよい二次元配列 |
| `JSON` | null、真偽、整数、小数、文字列、配列、オブジェクト |
| `任意<T>` | 値あり、または値なし |
| `結果<T,E>` | 成功値 `T`、または失敗値 `E` |
| `バイト列` | 0〜255 の不変な列 |
| `HTTP要求` | 経路、問い合わせ、ヘッダー、本文を持つ不変要求 |
| `HTTP応答` | status、ヘッダー、展開済みの完全本文を持つ不変応答 |
| `JSON形状` | JSONの種類、必須・任意member、配列要素、null許容を表す不変形状 |

回復可能な失敗には `JSON解析失敗`、`UTF8復号失敗`、`Base64復号失敗`、`HTTP送信失敗`、
`ファイル読取失敗`、`ファイル書込失敗`、`区切りテキスト解析失敗`、`JSON形状失敗`があります。

`JSON形状`と`JSON形状失敗`は直接表示・比較できません。形状検証は
`結果<JSON,配列<JSON形状失敗>>`を返し、失敗の種類、JSON Pointer path、期待種類、実際種類だけを
専用の取出し語で参照できます。

## 型の表記

利用者定義単語のスタック効果では、次の具体型構文を使います。

```text
型 := スカラー型
    | 配列<型>
    | 任意<型>
    | 結果<型,型>
```

`結果`の2引数は成功型、失敗型の順です。標準形では山括弧とASCIIの`,`の周囲に空白を置きません。
裸の`配列`、`任意`、`結果`、空の型引数、辞書専用制約の`T`、`E`、`N`、`数値`、`表示可能`は
具体型ではなく、利用者の宣言には書けません。利用者定義の型、型別名、型変数、ジェネリック単語もありません。

`任意`と`結果`は任意の具体型を再帰的に包めます。型構築子の深さは根から葉まで最大256段です。
これとは別に、`配列`構築子はラッパー越しに数えて各経路で最大2個です。配列の直下に置ける型には
制限がありますが、`任意<T>`と`結果<T,E>`は配列要素にできます。具体例は次節を参照してください。

## 任意・結果を要素に持つ配列

`任意<T>`と`結果<T,E>`は配列要素型にできます。各要素は型引数まで含めて完全に同じ具体型でなければ
なりません。成功と失敗は同じ`結果<T,E>`の別状態なので、同じ配列へ混在できます。

```text
【1 を 任意にする、2 を 任意にする】
【41 を 成功にする<整数,文字列>、「失敗」を 失敗にする<整数,文字列>】
```

配列型構築子の上限は、ラッパーの内側もたどって型全体で数えます。最大2個なので、
`配列<任意<配列<整数>>>`は利用できますが、`配列<任意<配列<配列<整数>>>>`は利用できません。

表示可能性、等値比較可能性、traceの非開示は、配列とラッパーを通して中身の型から決まります。
ラッパーで包むことによって、直接表示・比較できない型の制限を回避することはできません。

## 不変値

配列、JSON、バイト列、HTTP要求は生成後に変化しません。「設定する」「置き換える」「追加する」という
単語は、元の値を保ったまま変更済みの新しい値を返します。必要なら返り値を変数へ代入します。

```text
数列は 変数 【1、2】。

数列 と 3 を 配列の末尾へ追加する
を 数列 に 入れる
```

## 型変換

代表的な明示変換は次のとおりです。

| 変換 | 単語 |
|---|---|
| `整数` → `小数` | `小数に変換する` |
| 小数部が0の `小数` → `整数` | `整数に変換する` |
| `小数` → 丸めた `整数` | `整数に丸める` |
| 数値 ↔ `文字列` | `整数を文字列に変換する` など |
| BSB のスカラー ↔ `JSON` | `整数をJSONに変換する` など |
| `文字列` ↔ `バイト列` | UTF-8 変換語 |
| `バイト列` ↔ Base64 `文字列` | Base64 変換語 |

変換できない値や不正な外部データの扱いは単語ごとに異なります。通常の診断で終了する操作と、
`結果<T,E>` を返して分岐できる操作があるため、[組み込み語](builtins.md)から対応仕様を確認してください。

## 表示

`表示する` は改行せず、`一行表示する` は最後に LF を1個出力します。数値、真偽、文字、文字列、配列、
JSON、任意値、結果値などに決定的な表示形式があります。バイト列や HTTP 値は秘密・本文の不用意な公開を
避けるため、内容を直接表示できません。明示的に安全な表現へ変換してから表示します。
