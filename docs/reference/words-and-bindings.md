# 単語、定数、変数

## 利用者定義単語

```text
名前とは （入力型... -- 出力型...）
    本体
こと。
```

単語は入力をデータスタックから受け取り、出力をスタックへ残します。入力や出力がなければ、その側を空に
します。すべての通常終了経路と `戻る` は、宣言した出力と同じスタック形状でなければなりません。

```text
二倍とは （整数 -- 整数）
    2 を 掛ける
こと。
```

利用者定義単語は前方参照と再帰呼出しができます。オーバーロード、可変長引数、利用者定義ジェネリック型は
ありません。

## `メイン`

プログラムの入口は、入力も出力もない `メイン` です。

```text
メインとは （--）
    処理
こと。
```

`メイン` はちょうど1回定義します。入口専用なので、ほかの単語から呼び出すことはできません。

## 定数と変数

```text
名前は 定数 初期値。
名前は 変数 初期値。
```

型は初期値から推論します。定数は初期化後に変更できません。変数は、宣言時と同じ型の値へ代入できます。

```text
回数は 変数 0。

回数 と 1 を 足す を 回数 に 入れる
```

値の参照は名前だけで行い、現在値をスタックへ1個積みます。代入は値を1個消費し、何も返しません。

## 大域と局所

トップレベルの宣言は大域です。大域値はソース順で `メイン` より前に初期化され、すべての単語から
参照できます。大域初期値からは、すでに初期化済みの大域値だけを参照できます。

単語本体や制御ブロック内の宣言は局所です。宣言の直後から、その宣言を直接含む範囲の末尾まで有効です。
内側の範囲から外側の局所値は見えますが、兄弟の分岐や終了したブロックの局所値は見えません。

名前の隠蔽は禁止されています。局所名を、大域名、外側の局所名、単語名、組み込み名、予約名と同じ名前には
できません。

## 初期値の制限

初期値は空のスタックから評価し、値をちょうど1個残す必要があります。リテラル、初期化済みの名前付き値、
副作用のない許可済み組み込み語を使えます。利用者定義単語、画面出力、分岐、反復、宣言、代入は使えません。
