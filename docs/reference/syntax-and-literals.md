# 構文とリテラル

## ソースファイル

ソースは UTF-8 です。先頭の BOM は1個だけ読み飛ばします。空白、タブ、全角空白、改行、`、`、`，` は
トークンの区切りです。`#` から行末まではコメントになります。

```text
# 税込み価格を表示する
1000 と 0.10 を 掛ける
```

ソースの大部分は空白で区切ります。ただし定義名の `とは`、宣言名の `は`、定義終端の `こと。` は
それぞれ決められた形で隣接させます。

## 単語定義

```text
単語名とは （入力型... -- 出力型...）
    本体
こと。
```

全角括弧 `（ ）` と ASCII 括弧 `( )` のどちらも使えますが、左右は同じ種類にします。入力・出力が
ない側は空にします。

```text
メインとは （--）
こと。

二倍とは （整数 -- 整数）
    2 を 掛ける
こと。
```

## 助詞

`を`、`に`、`と`、`から`、`で` は読みやすさのために置けます。実行時の値ではなく、スタックを
変えません。不自然な位置では警告されます。

```text
20 と 22 を 足す
1 と 8 と 2 と 最近接偶数丸め で 精度指定で割る
```

助詞は省略できますが、宣言と代入に含まれる `は`、`を ... に 入れる` は構文の一部なので省略できません。

## リテラル

| 種類 | 例 | 備考 |
|---|---|---|
| 整数 | `0`、`42`、`-12` | 任意精度。先頭の `+` と不要な先頭0は不可 |
| 小数 | `0.5`、`-12.30`、`1.25E-2` | 正確な10進小数。指数表記を利用可能 |
| 真偽 | `はい`、`いいえ` | 条件構文が受け取る型 |
| 文字 | `'A'`、`'あ'` | 拡張書記素クラスタ1個 |
| 文字列 | `「こんにちは」`、`"hello"` | かぎ括弧またはASCII二重引用符 |
| 配列 | `【1、2、3】` | 同じ具体型の要素。配列型構築子は全体で2個まで |
| 正規表現 | `正規表現「(?P<年>[0-9]{4})」` | RE2 系の構文 |

文字列では `\\`、`\"`、`\n`、`\r`、`\t`、`\u{...}` などのエスケープを利用できます。
かぎ括弧文字列では引用符として `「` と `」` を使いますが、内容のエスケープ規則は同じです。

配列リテラルは空にできません。空配列は `空の整数配列`、`空の文字列配列` など、型が名前に含まれる
組み込み値で作ります。要素には`任意<T>`と`結果<T,E>`も使えますが、すべての要素で型引数まで含む型を
一致させます。JSON はソースリテラルを持たず、文字列から解析するか組み込み値・変換語で作ります。

## 名前

識別子には Unicode を使用できます。処理系は全角英数字の限定変換と NFC 正規化を行い、紛らわしい文字、
不可視文字、予約名の利用を診断します。同じ正規化結果になる名前は別の名前として宣言できません。

## 整形

`format` は意味を変えずに空白、字下げ、引用符、区切りを標準形へ整え、標準出力へ表示します。
入力ファイルは上書きしません。

```shell
java -jar build/libs/bsb-0.1.0-SNAPSHOT-all.jar format program.bsb
```
